# Documentação Técnica

Esta pasta reúne orientações específicas para contribuir com este toolkit de análise de dados.

- `coding-standards.md`: convenções de código, modularidade, logging e tratamento de dados.
- `testing.md`: estratégia de testes e validação prática para CLI, GUI, conectores e artefatos.
- `tooling.md`: ambiente atual do projeto, comandos locais e uso de `pre-commit`.
- `packaging.md`: estado atual de empacotamento e cuidados antes de mudar a forma de distribuição ou execução.
