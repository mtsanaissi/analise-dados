# Review Agent Instructions Before Work

## Summary

Read the project instruction files before starting implementation to avoid preventable convention drift.

## Context

The legacy memory logs recorded repeated mistakes caused by skipping or under-reading the assistant guidance for this repository.

## Remember

Review the current project instruction files before non-trivial work and treat them as operational constraints during implementation, testing and documentation updates.
